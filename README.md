# ClearTaskbar

Миниатюрный легковесный фоновый процесс для Windows 10, делающий панель задач прозрачной на рабочем столе и возвращающий стандартный вид при переключении на окна приложений и меню «Пуск».

## Особенности
- **0% CPU** в режиме ожидания (работает через системные хуки Win32 `SetWinEventHook` без таймеров и циклического опроса).
- **Чистый рабочий стол**: когда активно окно рабочего стола — панель 100% прозрачна.
- **Интеллектуальное переключение**: при открытии меню «Пуск» или переключении на любое окно приложения панель возвращает стандартную непрозрачность.
- Иконка в системном трее с возможностью корректного выхода (панель возвращается в исходное состояние).
